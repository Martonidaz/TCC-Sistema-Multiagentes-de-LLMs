Para simular um clique duplo no Selenium com Python Bindings (PyAutoGUI), você pode usar a função `double_click()`. Aqui está como fazer isso, seguindo os exemplos do manual técnico fornecido:

```python
from selenium import webdriver
import pyautogui

# Inicialize o driver Selenium e navegue até um local na tela onde você deseja realizar ações. Por exemplo:
browser = webdriver.Firefox()  # ou outro browser se preferir, como ChromeDriver para Google Chrome.
browser.get('http://www.exemplo.com')  # Substitua pelo URL real que você está testando.

# Encontre o elemento no qual deseja realizar ações com PyAutoGUI:
element = browser.find_element_by_id('elementId')  # Use .text, xpath ou outro método para encontrar um elemento específico.

# Simule uma acção de clique duplo no local onde o elemento está presente na tela (x e y coordenadas):
pyautogui.doubleClick(element_position_x, element_position_y)  # Substitua por as posições reais da janela do navegador Selenium.
```

Lembre-se de que PyAutoGUI é uma biblioteca externa ao Selenium e não faz parte dos Bindings oficiais para Python com o Selenium, mas pode ser usada em conjunto quando necessário. Se você precisar usar comandos específicos do PyAutoGUI dentro da mesma sessão de teste que está executando o driver Selenium, certifique-se de lidar corretamente com a interação entre as duas bibliotecas para evitar conflitos ou comportamentos inesperados.

Se você não tiver certeza sobre como encontrar as posições reais da janela do navegador onde o elemento está presente, pode usar `pyautogui.position()` dentro de um loop até que a acção seja concluída para obter essas coordenadas:

```python
while True:  # Loop infinito ou com uma condição específica para parar quando necessário.
    pos = pyautogui.position()
    if element_present(pos):  # Defina a função 'element_present' que verifica se o elemento está visível na tela em relação à posição atual do mouse.
        break
```

Lembre-se de substituir `'http://www.exemplo.com'` e `'elementId'` pelos valores reais para a URL da página que você deseja testar e o ID ou seletor CSS/XPath real do elemento na tela, respectivamente.
